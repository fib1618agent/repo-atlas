# Attribution and License Review Prompt

Review the Graphify and CodeGraph repositories used as RepoAtlas references.

Create `ATTRIBUTIONS.md`.

For each project record:

- repository URL
- license
- version/commit studied
- copyright/author notices
- attribution requirements
- NOTICE requirements if any
- whether source reuse appears permitted by the repository license
- whether modifications must be marked
- dependency/license implications

Do not make legal conclusions beyond what the license/repository text supports.

Distinguish:

1. conceptual inspiration
2. architectural adaptation
3. copied source code
4. dependency reuse

Do not copy source code until the applicable license has been reviewed.
