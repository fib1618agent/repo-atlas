# Reference Research Prompt

RepoAtlas is evolving into a repository-scale Engineering Intelligence platform.

Reference repositories:

- Graphify
- CodeGraph

Treat them as research inputs, not implementation sources to copy blindly.

Inspect both repositories and create:

- `GRAPHIFY_RESEARCH.md`
- `CODEGRAPH_RESEARCH.md`
- `COMPARATIVE_ANALYSIS.md`
- `ADOPTION_MATRIX.md`
- `ENGINEERING_LINEAGE.md`
- `REPOATLAS_EVOLUTION.md`

Study:
AST, symbols, relationships, graph, evidence, confidence, flows/processes, impact, blast radius, indexing, BM25, vector retrieval, MCP, agent context, source snapshots, incremental indexing, persistence, performance, testing, and language support.

For every important finding record exact repository/file/symbol evidence where possible.

Classify:
ADOPT / ADAPT / INSPIRE / DEFER / REJECT.

Separate:

- Graphify-originated ideas
- CodeGraph-originated ideas
- shared ecosystem ideas
- RepoAtlas additions
- unresolved claims

Record attribution and license considerations.

Do not modify RepoAtlas source, add dependencies, or copy implementation during research.
