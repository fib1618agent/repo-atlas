# Phase 09 — Code Intelligence UI

## Objective

Extend the existing RepoAtlas visual experience from repository atlas to code intelligence without replacing the atlas.

## Navigation

Repository Atlas → Repository Detail → Code Universe → Code Graph → Process → Impact → Evidence

## Requirements

1. Preserve the repository marble experience.
2. Selecting a repository exposes code intelligence.
3. Symbols have inspectable details.
4. Relationships are navigable.
5. Processes are inspectable.
6. Static impact is inspectable.
7. Evidence state is visible.
8. Search spans repository and code intelligence.
9. Desktop/tablet/mobile behavior remains usable.
10. Accessibility is preserved.

## Visual direction

Visualization-first, restrained semi-dark material surfaces, depth, whitespace, strong hierarchy, and no dense administrative dashboard.

## Non-goals

Replacing the atlas, rendering every AST node simultaneously, or exposing unauthorized source.
