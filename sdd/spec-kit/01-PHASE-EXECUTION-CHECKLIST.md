# Phase Execution Checklist

For each phase:

- [ ] Read the phase `PHASE.md`
- [ ] Read previous phase artifacts
- [ ] Inspect current RepoAtlas implementation
- [ ] Read relevant research/attribution material
- [ ] Run Spec Kit `specify`
- [ ] Clarify unresolved requirements
- [ ] Generate plan/research/data-model/contracts where needed
- [ ] Generate checklist
- [ ] Generate tasks
- [ ] Run `analyze`
- [ ] Implement in dependency order
- [ ] Run unit tests
- [ ] Run integration tests
- [ ] Run lint/type checks
- [ ] Inspect diff
- [ ] Check regression against existing RepoAtlas
- [ ] Update documentation
- [ ] Update attribution if applicable
- [ ] Run `converge`
- [ ] Commit the phase as a reviewable unit
