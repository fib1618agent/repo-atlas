# RepoAtlas Phase-Wise Spec-Driven Development Package

This package is the working document set for implementing RepoAtlas as a repository-scale Engineering Intelligence platform using GitHub Spec Kit / Specification-Driven Development.

## Phase sequence

1. `01-foundation` — Repository Source Abstraction
2. `02-source-snapshot` — Immutable Source Snapshot
3. `03-ast-symbols` — Polyglot AST and Symbol Intelligence
4. `04-engineering-graph` — Engineering Intelligence Graph
5. `05-knowledge-retrieval` — Engineering Knowledge and Hybrid Retrieval
6. `06-process-discovery` — Process Discovery
7. `07-impact-analysis` — Static Impact and Blast Radius
8. `08-mcp-agent-interface` — RepoAtlas MCP
9. `09-code-intelligence-ui` — Code Intelligence UI
10. `10-integration-hardening` — Integration, Performance, Security and Convergence

## Spec Kit lifecycle

`constitution → specify → clarify → plan → checklist → tasks → analyze → implement → converge`

The phase documents are inputs to the canonical Spec Kit artifacts. Use the existing `.specify/` configuration in RepoAtlas.

## Reference-project policy

Graphify and CodeGraph are research inputs. Study them, extract applicable architectural ideas, document attribution/license requirements, and make explicit ADOPT/ADAPT/INSPIRE/DEFER/REJECT decisions. Do not copy implementation blindly.

## Global definition of done

A phase is complete only when requirements and acceptance scenarios are implemented and verified, existing RepoAtlas behavior is preserved, evidence/provenance semantics are intact, failure paths are tested, documentation is updated, and the phase is converged into a reviewable state.
